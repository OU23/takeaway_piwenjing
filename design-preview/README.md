# 用户端 · 设计演示稿（design-preview，原名 user-web）

> ⚠️ 这是 **静态设计演示稿（Mock）**，不是本项目的真实可运行用户端原型。

## 定位
- 用途：按 `C:\Users\EDY\Desktop\ui\05-*` 用户端高保真稿，做**纯视觉 / 交互还原**的轻量演示，
  方便非技术汇报直接打开浏览器查看，无需后端。
- 数据：全部写死在 `src/mock/*`（首页为主），无网络请求。
- 形态：移动端 375/390 视口，桌面以「手机壳」外框展示（端口 `8082`）。

## 与真实原型的区别
| 项目 | design-preview（本目录） | frontend/（真实原型） |
|---|---|---|
| 性质 | 设计演示稿，静态 Mock | 可运行原型，接真实后端 |
| 后端 | 无 | Spring Boot 3 + MySQL，端口 8090 |
| 数据 | 写死 Mock | 真实接口 + 幂等/状态机/越权校验 |
| 链路 | 仅首页 + 各 Tab 占位 | 首页/附近/店铺/结算/收银台/订单/消息/我的 全链路 |
| 验收 | 视觉演示 | `scripts/e2e_test.py` 118 项断言通过 |
| 移动端 | H5 仅桌面演示 | Capacitor 7 打包真 APK（Android） |

**结论：交付与演示以 `frontend/` 为准；本目录仅作视觉稿参考，不要当成可下单的产品。**

## 运行
```bash
npm install
npm run dev      # http://localhost:8082
```
接口接入时，把 `src/mock/*` 换成 `frontend/src/api` 风格的请求即可（设计令牌已对齐 SRS 5.4）。
