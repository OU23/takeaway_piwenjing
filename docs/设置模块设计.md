# 设置功能模块 · 设计与实现说明（SRS 9.11）

> 范围：用户端 H5（frontend）。模块入口：`我的 → 设置`（原占位项已接通 `/settings`）。
> 代码位置：前端 `frontend/src/store/settings-schema.js`、`store/settings.js`、`views/SettingsView.vue`；后端 `UserController(/api/v1/user/settings)`、`UserSettingService`、`UserSettingMapper`、`entity/UserSetting`；SQL `db/migration-setting.sql`（已同步进 `schema.sql`）。

---

## 一、分类与层级结构（两级，页面即结构）

设置页按「分组卡片」单层呈现，无多级菜单，操作路径最短：**我的 → 设置 → 单项操作（一次点击/一次弹层）**。

```
设置 /settings
├─ 通用          appearance.theme（单选）   appearance.fontSize（单选）
├─ 消息通知       notification.order（开关） notification.promo（开关）
│                notification.quietMode（开关）
│                └ 开启时内联展开 quietStart / quietEnd（时刻）
├─ 隐私          privacy.personalization（开关）
├─ 账户与安全     注销账号（危险操作，确认弹层）
└─ 关于          版本 / 用户协议 / 隐私政策
底部：恢复默认设置（危险操作，确认弹层）
```

## 二、设置项清单（数据类型与默认值）

| 键路径 | 名称 | 类型 | 默认值 | 取值范围 | 生效方式 |
|---|---|---|---|---|---|
| appearance.theme | 外观模式 | enum | `system` | light / dark / system | 即时（CSS class） |
| appearance.fontSize | 字体大小 | enum | `standard` | small / standard / large | 即时（CSS class） |
| notification.order | 订单通知 | bool | `true` | true / false | 即时 |
| notification.promo | 营销推送 | bool | `false` | true / false | 即时 |
| notification.quietMode | 夜间免打扰 | bool | `false` | true / false | 即时 |
| notification.quietStart | 免打扰开始 | time | `23:00` | HH:mm | 即时 |
| notification.quietEnd | 免打扰结束 | time | `07:00` | HH:mm（允许跨零点） | 即时 |
| privacy.personalization | 个性化推荐 | bool | `true` | true / false | 即时（首页排序读取） |

所有设置**改完即时生效，无需重启/保存按钮**。

## 三、数据结构定义

**存储结构**（`user_setting` 表，一行一用户）：

```sql
user_setting (
  user_id    BIGINT PK,        -- app_user.id，一对一
  settings   TEXT,             -- JSON，仅存"改过默认值的键"
  updated_at DATETIME
)
```

**JSON 结构**（嵌套分组，键路径即上表）：

```json
{ "appearance": { "theme": "dark", "fontSize": "large" },
  "notification": { "promo": true, "quietMode": true, "quietStart": "23:00", "quietEnd": "08:00" },
  "privacy": { "personalization": false } }
```

**运行时结构**：前端 store 中永远是 `DEFAULT_SETTINGS ∪ 用户已保存值` 的完整对象（`normalizeSettings` 归一化：未知键丢弃、非法值回落默认），任何页面读取都不需要判空。

**API 契约**（均需登录，`/api/v1/user/settings`）：

| 方法 | 请求体 | 返回 | 说明 |
|---|---|---|---|
| GET `/settings` | — | 完整设置对象 | 默认值 ∪ 已保存值 |
| PUT `/settings` | 补丁 `{"appearance.theme":"dark"}` | 更新后完整对象 | 增量合并；键为「分组.键」点分路径 |
| DELETE `/settings` | — | — | 重置为默认（删行） |

## 四、存储与持久化（双通道）

1. **localStorage（`xg_user_settings`）**：每次修改立即写入；未登录同样生效；应用启动时同步恢复（挂载前应用主题，避免首帧闪白）。
2. **服务端 `user_setting` 表**：登录后 800ms 防抖合并同步（连续拖动开关只发一次 PUT）；启动时 `GET` 拉取并以服务端为准覆盖本地（跨设备漫游）。
3. **降级策略**：同步失败静默降级为本地模式（`syncState=error`，设置页底部有状态提示文案）；localStorage 损坏时按首次使用处理，不会白屏。

## 五、生效机制

- **即时生效类**：主题/字号在 `applyAppearance()` 中切换 `<html>` 上的 `theme-dark / fs-large` 等 class，全局 CSS 令牌（`tokens.css`）随 class 变化，全站无需刷新；`theme=system` 时监听 `matchMedia` 跟随系统切换。
- **业务订阅类**：通知/隐私开关即时更新 store，消息推送与首页排序模块在下次读取 store 时采用新值（推送侧由服务端在下发前读取用户设置）。

## 六、权限控制

| 角色 | 可见 | 可改 |
|---|---|---|
| 用户（本人） | 全部设置项 | 全部设置项 |
| 未登录访客 | 无（路由守卫跳登录页） | 仅本地临时（同步被跳过） |
| 后端 | — | 接口强制 `requireUserId()`，只能读写**自己的**设置（无 id 参数，userId 取自令牌） |

- 设置接口挂 `/api/v1/user/**` 鉴权链下，不存在横向越权面（不接受任何用户 id 输入）。
- 骑手端/商家端/运营后台各端独立登录态，互不共享用户设置；运营后台对用户设置只读不写（无管理接口）。
- 注销账号为危险操作：双重确认弹层 + 7 天冷静期文案，正式实现时需后端删除接口（当前为 P2 占位）。

## 七、输入校验与异常处理

**双侧校验**（前端 `settings-schema.js#validateSetting` 先拦，后端 `UserSettingService#validate` 兜底，规则一致）：

- 白名单键：未登记的键直接拒绝/丢弃，杜绝脏数据入库；
- 枚举项：值必须命中候选集；布尔项：必须为 true/false；
- 时刻项：`HH:mm` 正则 + `LocalTime.parse` 双重校验；
- 跨项校验：免打扰开始=结束时刻时本地回滚并提示（区间无法解释）；
- 后端错误码 10005（参数不合法），错误文案可直接透出给用户。

**异常处理**：

- 服务端 JSON 损坏 → 按「无自定义设置」处理，页面不挂，下次保存覆盖脏数据；
- 同步失败 → 静默降级本地模式，状态提示条说明；
- 校验失败 → 控件回显旧值 + toast 具体原因；
- 隐私模式 localStorage 写入失败 → 仅本会话生效，不中断。

## 八、重置为默认值

- **单项重置**：单项改回默认值即普通 `set`（无特判）。
- **全量重置**：设置页底部「恢复默认设置」→ 确认弹层 → 本地立即恢复默认并应用；已登录时调 `DELETE /user/settings` 删行，云端同步清理。
- 后端重置实现为删行（幂等、零残留），下次 GET 自然回落默认值。

## 九、界面布局与交互逻辑

**布局**（复用全局设计令牌，`page--notab` + NavBar）：

- 每个分组一张卡片（`st-card`），组内行间 1px 分割线；
- 行结构：左侧「标签 + 灰色说明」，右侧控件（开关 / 单选预览+chevron / 时刻输入）；
- 开关：44×26 滑块式，开态品牌橙，`role="switch"` 无障碍标注；
- 单选：行右侧显示当前值，点击弹底部 sheet，候选项高亮当前值并带勾选图标；
- 免打扰时段：开启 `quietMode` 后两行时刻选择内联展开（`showIf` 条件渲染），用原生 `<input type="time">` 保证移动端键盘体验；
- 底部：红色描边「恢复默认设置」按钮（弱化面积防误触）+ 云同步状态说明文字。

**交互路径**（每项 ≤2 步）：开关 1 步点击即生效；单选 2 步（点击行 → 选候选）；时刻 1 步（原生选择器）；重置 2 步（点击 → 确认）。

**扩展方式**：新增设置项只需 ① `DEFAULT_SETTINGS` 加默认值 ② `SETTING_ITEMS` 登记定义 ③ 后端 `ALLOWED` 白名单同步登记——页面 UI、校验、同步代码零改动；新增分组只需给设置项指定新的 `group` 名。
