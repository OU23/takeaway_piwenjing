# 项目改进报告（2026-11-10）

本轮按 2026-10-21 审查报告的 P0 清单完成**安全修复 + 密钥治理 + 仓库卫生 + 结构规范**四类改进。
后端、frontend、admin-web 均编译/构建通过，e2e 全链路 188/188 通过。

## 一、安全修复（对应审查报告 P0）

### S1 支付回调无验签 —— 已修复
- `backend/.../service/PayService.java`：`/pay/notify/{payNo}` 现在必须携带
  `X-Pay-Sign = HMAC-SHA256(payNo|amount|tradeNo, xingguang.pay.notify-secret)`，
  且报文 `amount` 必须与支付单金额一致，否则拒绝结算（金额比对 + 恒定时间比对）。
- 模拟通道改为 **prepay 时在服务端事务内同步结算**，前端不再调用回调接口：
  - `frontend/src/views/PayView.vue`：删除 `notifyPay` 调用，非 SUCCESS 时提示等待渠道确认；
  - `frontend/src/api/index.js`：移除 `notifyPay` 导出。
- 新增配置 `xingguang.pay.notify-secret`（环境变量 `XG_PAY_NOTIFY_SECRET`）。

### S2 鉴权靠请求头直传 —— 已修复（受众隔离令牌）
- `support/TokenCodec.java`：令牌载荷升级为 `id.aud.exp`，受众
  `USER / RIDER / ADMIN / MERCHANT` 四端互不通用（用户令牌调不了骑手/后台接口）；
  历史无受众令牌仅对 USER 兼容，随 7 天 TTL 自然淘汰。
- `support/CurrentUser.java`：**移除 `X-User-Id` 信任**，仅接受 `Authorization: Bearer`；
- `support/CurrentRider.java`：`X-Rider-Id` 直传移除，`X-Rider-Token` 必须为 RIDER 受众签名令牌；
- `support/CurrentAdmin.java` / `CurrentMerchant.java`：改为验签令牌 + 查库校验状态；
- 四个登录入口全部改签受众令牌并返回 `expiresAt`：
  `AuthService`（USER）、`AdminController.login`（ADMIN）、`MerchantService.login`（MERCHANT）、`RiderService.login`（RIDER）。

### S3 未认证请求自动获得超管权限 —— 已修复
- `CurrentAdmin` 不再无条件回落演示超管；仅当
  `xingguang.auth.demo-identity-enabled=true`（默认 true，仅限本地开发/e2e）时回落。
- 新增 `config/StartupGuard.java`：启动时对 mock-pay / mock-sms / 演示身份 / 默认密钥逐项告警，
  把"演示可用"与"生产可用"的边界显式化（生产设置 `XG_DEMO_IDENTITY=false` 即全部收紧为 401）。

### S4 `/admin/orders/{orderNo}/advance` 缺权限校验 —— 已修复
- `AdminService.advance()` 补 `currentAdmin.requireManage()`。
- 同时完成 M14：用户端 H5 移除 `/admin` 路由、`AdminView.vue`、`adminAdvance` 等
  后台接口导出与"模拟推进"调试卡片，运营能力统一收敛到 admin-web。

### S5 App 全链路允许明文 HTTP —— 已修复
- `frontend/capacitor.config.json`：`androidScheme: https`、`allowMixedContent: false`。
- 新增 `frontend/android/app/src/main/res/xml/network_security_config.xml`：
  默认禁明文，仅对 `10.0.2.2` / `localhost` / `127.0.0.1` 放行（本地模拟器联调）；
  生产打包删除该例外即全量强制 HTTPS。
- `AndroidManifest.xml`：改用 `android:networkSecurityConfig` 引用上述配置。

### S6 前端一键提权为超管 —— 已修复
- `admin-web/src/store/auth.js`：删除 `switchRole()` 与 `DEMO_ACCOUNTS`，
  角色只能由登录接口返回值决定；
- `admin-web/src/layout/AdminLayout.vue`：移除"演示角色"下拉框；
- `admin-web/src/views/LoginView.vue`：演示账号快捷填充仅在 `import.meta.env.DEV` 存在，
  生产包不含，且不再预填密码。

### 附带完成的低代价高危项
- **H3** `WebConfig`：CORS 从 `*` 白名单化（默认本机 4 个 dev server，
  生产用 `XG_CORS_ORIGINS` 注入正式域名）。
- **H8** `GlobalExceptionHandler`：系统异常不再回传 `e.getMessage()`（防 SQL 细节泄露）。
- **mock-pay 治理**：`StartupGuard` 启动告警（见上），保留 `xingguang.mock-pay-enabled` 开关。
